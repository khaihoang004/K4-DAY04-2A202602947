Dùng biểu tượng ⚙️ (Settings) để chuyển giữa Chat mode và Test mode.

- **Chat mode:** hội thoại tự do với agent.
- **Test mode:** chọn sẵn test case trong data/eval_*.json để chạy, không cần gõ tay.
Ở cả hai mode, mỗi lượt trả lời sẽ có một khối 🔍 Debug trace (có thể mở/thu gọn) chứa toàn bộ tool calls, arguments và tool results — tách riêng khỏi phần hội thoại chính.
